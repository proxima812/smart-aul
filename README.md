# Smart Aul

Fabric-мод для Minecraft 1.21.11: самостоятельные жители, рост деревень до города и основание отдельных поселений.

- Название: **Smart Aul**.
- ID мода: `smart_aul`.
- Версия разработки: `1.1.0-dev`.
- Minecraft 1.21.11, Fabric Loader 0.18.4+, Java 21, Fabric API.

## Что изменено

Темп развития по умолчанию ×3: рабочие действия, глубокая добыча, взросление новых жителей и офлайн-развитие ускорены. Строитель обрабатывает до трёх блоков за действие; каждый блок отдельно проверяется на досягаемость, наличие материала и допустимость изменения мира. Это настройки темпа, а не обещание ровно трёхкратного сокращения времени до города: пути, ресурсы, кровати и загрузка чанков продолжают влиять на результат.

Ремонт больше не забирает всех строителей: при активной стройке выделяется один ремонтник, а единственный строитель продолжает жильё. Город определяется по населению от 32 жителей и 12 завершённым общественным домам, построенным системой. Исходные ванильные дома в этот счётчик не входят. После достижения города разрешается автоматическая отправка новых экспедиций; ручная отправка доступна от 24 жителей при достаточных запасах.

Новая деревня основывается пятью настоящими переселенцами. Она получает собственный ID, колокол, склад, старейшину и работников; для первых четырёх работников сохраняются фермер, строитель, лесоруб и шахтёр; сохраняет ID родительской деревни. Повторное начальное создание ванильных жителей для неё отключено. Территории и цели других экспедиций учитываются при выборе места и дальнейшем расширении. Неудавшаяся экспедиция получает приказ вернуться, сохраняя оставшийся груз.

## Команды

- `/smart_aul progress` — уровень поселения, цели города, состояние стройки и подготовки переселения.
- `/smart_aul settlements` — поселения текущего измерения, координаты, население и родительские связи.
- `/smart_aul settle` — подобрать загруженную площадку для новой деревни.
- `/smart_aul settle X Y Z` — отправить экспедицию в указанную точку.
- `/smart_aul recall` — вернуть экспедицию ближайшего поселения с оставшимся грузом.
- `/smart_aul status` — подробная диагностика жителей, материалов и заданий.

`settle` и `recall` требуют прав оператора; автоматическое развитие работает без команд. Старый корень `/smartcolonies` сохранён как совместимый псевдоним. Постановочные команды `film` предназначены для отдельных тестовых миров; обычная отправка их не требует и не выдаёт бесплатный капитал.

## Настройки

Основной файл: `config/smart_aul.json`. При первом запуске старый `smart_colonies.json` копируется в новый файл, если нового ещё нет. Исходный файл сохраняется, существующие новые настройки не перезаписываются. Новые поля добавляются при загрузке старого JSON.

Поля секции `village`:

| Поле | По умолчанию | Назначение |
|---|---:|---|
| `development_speed` | 3 | Множитель темпа, 1..8 |
| `builder_blocks_per_action` | 3 | Блоков за действие, 1..8 |
| `city_population` | 32 | Население для статуса города |
| `city_houses` | 12 | Завершённые общественные дома для города |
| `automatic_settlement_requires_city` | true | Автопереселение после достижения города |
| `settlement_min_population` | 24 | Минимальное население для отправки |
| `settlement_min_distance` | 256 | Минимальное расстояние до новой деревни |
| `settlement_max_distance` | 512 | Максимальное расстояние |
| `settlement_border_gap` | 32 | Зазор между границами поселений |
| `settlement_retry_ticks` | 600 | Пауза между автоматическими попытками |
| `settlement_cooldown_ticks` | 12000 | Пауза после завершения/возврата экспедиции |
| `settlement_capital_interval_ticks` | 400 | Интервал подготовки капитала |
| `settlement_timeout_ticks` | 18000 | Время до приказа вернуться |

20 тиков ≈ 1 секунда при нормальной скорости сервера. Дальности дополнительно ограничиваются уже существующими территориями. Кандидат должен быть загружен, безопасен для жителей и не затрагивать землю и постройки игрока. Маршрут экспедиции нужно загружать, например следуя за группой. Принудительная загрузка мира модом не добавлена.

Для совместимости сохранений внутренние имена ресурсов, предметов, памяти ИИ и файла данных `smart_colonies` сохранены. Публичный ID мода — `smart_aul`; Java-пакеты восстановленного проекта пока остаются `net.smartcolonies`.

## Сборка и проверки

```powershell
.\gradlew.bat build
.\gradlew.bat developmentRegression
```

Готовый мод: `build/libs/smart-aul-1.1.0-dev.jar`. Устанавливайте его вместо предыдущего JAR. Архив `-sources.jar` не предназначен для папки `mods`.

Сборка использует JDK 21 для компиляции и совместимый с Gradle 9.4.1 JDK для запуска Gradle; в этом окружении используется JDK 25.

Регрессионная задача включена в `check`. Она проверяет ограничения настроек, ускорение, границы территорий, распределение ремонта, реальные NBT-сохранения стройки и экспедиции, совместимость команд и перенос конфига. Отдельный запуск `runDevelopmentServer` использует каталог `recovery/development-server`, не пользовательский мир.

Результаты текущей игровой проверки и её ограничения: `recovery/smart-aul-validation.md`. История восстановления оригинала: `recovery/RESTORATION_README_RU.md`. Проект распространяется по лицензии MIT; см. `LICENSE`.
