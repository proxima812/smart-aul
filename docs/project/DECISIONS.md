# Решения

Короткие записи о решениях, которые влияют на дальнейшую работу. Новые — сверху.
Отменённое решение не удаляется: пометьте `заменено D-NNN`.

## D-007 · Дальние маршруты — возобновляемый взвешенный A* (2026-11-09, T-014)

Цели дальше 48 блоков (`VillagerNavigation.LONG_ROUTE_SQ`) планируются
`NavigationSearch.Session`, который продолжает тот же поиск в следующих тиках:
срез 3 мс, не больше одного среза на мир за тик (`searchSlices`) и в рамках квоты
`ColonyManager.x5ll9elqpk1a4`; всего до 24 000 узлов; эвристика с весом 125 %
(путь не длиннее 1,25 оптимального; на ловушке в 3 раза меньше узлов). Пока поиск
идёт, житель стоит. Незавершённый поиск сбрасывается при смене цели больше 4 блоков,
смещении от старта больше 4 блоков или паузе продолжения больше 200 тиков. Если
лимит исчерпан, путь ведёт к узлу фронтира с минимальной f, а не к ближайшему к
цели по прямой. Короткие цели работают как раньше: один срез, 6000 узлов,
оптимальный A* (его проверяют Dijkstra-тесты). Причина: при едином бюджете 3 мс
дальний путь был жадным и застревал (B-002). Цена: до 3 мс за тик на мир при
активном дальнем поиске; учесть в нагрузочном тесте R-001/T-016.

## D-005 · Заявки материалов и владение грузом (2026-11-08, T-011)

Исходный поток: `Colony` хранит обнаруженные и управляемые склады;
`VillageStorageSensor` раз в 100 тиков запоминает ближайший загруженный склад.
`InventoryMaterials` считает содержимое, `VillagerInventory` выдаёт инструменты,
возвращает предметы и использует общий путь сдачи `ColonyManager`.
`VillageEconomy` рассчитывает размеры партий и потребности, а не хранит груз.
Добытчики сдают добычу через `WorkDiagnostics`/`ColonyManager`; этот путь сохранён.
`MaterialRequirement` — предикат и количество для подготовки переселенцев,
не сохраняемая заявка. Строитель (`HouseBuilderTask`) и ремонтник
(`ColonyTravelTask`) сами шли к складу. `RepairTask` только ставит начальный
склад; дороги не требуют предметов, стены расходуют общий запас транзакцией.

Новый путь: при загруженном живом курьере строитель/ремонтник создаёт конкретную
заявку на обычный предмет (до 32/16 штук); без курьера остаётся прежний путь.
Очередь колонии ограничена 128 записями, ключ — работник/предмет/позиция;
смена потребности отменяет прежнюю заявку работника. Приоритет ремонта 80,
стройки 50, срок 2400 тиков; lease `TimedReservation` — 200 тиков.
Истёкший lease освобождает исполнителя, не груз. Просроченный или отменённый
груз возвращается курьером в склад; если склада/места нет, остаётся в NBT.
Завершённая история очищается только для освобождения места в очереди.

Единственный владелец груза в пути — запись колонии, не инвентарь сущности.
Забор/передача и изменение счётчика происходят в одном серверном вызове.
Смерть или выгрузка курьера не выбрасывает вторую копию; после lease другой
курьер продолжает. При загрузке NBT lease сбрасывается, груз сохраняется.
Поддерживаются только стеки без изменённых компонентов (проверка сравнения
с обычным стеком предмета), поэтому ID/количество сохраняются без потери
имен, чар и прочих компонентов. Остальные предметы со склада не забираются.
Это гарантия штатных сохранений; аварийная несогласованная запись разных
ванильных файлов мира не является атомарной транзакцией мода.

`COURIER` добавлен строго после `CITIZEN`; роли по-прежнему пишутся строкой
`serializedName`, `byName` сохраняет fallback. При складе и населении от
`courier_min_population` (10, минимум 8) один из бюджета не менее восьми
работников выделяется курьеру; основные четыре профессии сохраняются.
Старый NBT без `material_requests` даёт пустую очередь. Код, схемы и тексты
MineColonies не использовались (D-001). Клиентский рендер, сеть и таверна не менялись.

## D-006 · Client GameTest ждёт состояние явно (2026-11-08)

В T-009 один запуск упал с `Network synchronizer in invalid state` (B-008).
В `loom.runs.clientGameTest` включён рекомендованный сообщением Fabric флаг
`fabric.client.gametest.disableNetworkSynchronizer`; серверный run не меняется.
Поэтому тест обязан явно ждать не только mesh после S2C, но и установленные
блоки на клиенте перед `waitForChunksRender` и скриншотами. Нельзя считать
завершение server.runOnServer подтверждением получения блоков клиентом.
При обновлении Fabric повторно проверить необходимость обхода.

## D-004 · Обходной Mixin для GameTest с локальными mappings (2026-11-08)

Локальные identity mappings оставляют у enum Minecraft имена Mojang, а Loom
переводит значения по умолчанию в аннотациях Fabric в intermediary. Java ищет
значение enum из аннотации через `Enum.name()`, поэтому GameTest не запускался.
Только в тестовом source set `gametest` Mixin `BlockRotationNamesMixin` меняет
`name()` четырёх значений `BlockRotation` на `field_*`; ordinal и сериализуемые
строковые ID не меняются. В релизный JAR он не входит. Если тестам понадобятся
другие enum из аннотаций, может потребоваться такой же обход; при смене mappings
обход нужно пересмотреть.

## D-003 · Учёт прогресса в `docs/project` (2026-11-08)

План, баги, планы на будущее и решения ведутся в Markdown внутри репозитория,
чтобы любой агент и человек видел одно состояние без внешних трекеров.
Каждый готовый шаг записывается в журнал `PLAN.md`. Правила — `AGENTS.md`.

## D-002 · Голограмма построек — клиентский рендер по данным сервера (2026-11-08)

Сервер отправляет только ещё не установленные блоки планов рядом с игроком
(лимиты радиуса и числа блоков); клиент рисует их белыми полупрозрачными.
Игроки без мода не затрагиваются. Детали — T-005.

## D-001 · MineColonies — только идеи (2026-11-08)

MineColonies распространяется под GPL-3.0, Smart Aul — под MIT. Код, схемы,
текстуры и тексты MineColonies не переносятся; заимствуются только механики,
реализация своя. Перевод проекта на GPL требует отдельного решения владельца.

Связанный риск: в `src/main/resources/data/smart_colonies/structure/village/`
лежат схемы ванильных деревень Minecraft (ресурсы Mojang) — учесть при публикации.

## D-000 · Унаследованные решения

- Сохранённые ID `smart_colonies` (ресурсы, NBT, память ИИ) не переименовываются —
  совместимость старых миров. Публичный ID — `smart_aul`.
- Локальные intermediary mappings; имена `class_*`/`method_*` не правятся.
- Навигация — собственный ограниченный A* по подходам Baritone, без его кода.
