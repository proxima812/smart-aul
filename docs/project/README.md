# Управление проектом Smart Aul

Здесь ведётся текущее состояние работ. Правила обновления — в `AGENTS.md`,
раздел «Учёт прогресса».

| Файл | Что хранит | Когда обновлять |
|---|---|---|
| [PLAN.md](PLAN.md) | Текущая итерация: задачи, статусы, исполнители, ветки, журнал готовых шагов | При взятии задачи, смене статуса, после каждого готового шага |
| [BUGS.md](BUGS.md) | Известные ошибки: воспроизведение, серьёзность, статус, исправление | При обнаружении, исправлении или отклонении бага |
| [ROADMAP.md](ROADMAP.md) | Идеи и планы на будущее, ещё не взятые в работу | При появлении идеи; при взятии — перенести в PLAN.md |
| [DECISIONS.md](DECISIONS.md) | Архитектурные и организационные решения с причинами | При решении, которое влияет на будущую работу |

Связанные каталоги:

- `docs/validation` — доказательства проверок (логи, отчёты, скриншоты) конкретных запусков.
- `docs/history` — история восстановления; не подтверждает текущее поведение.
- `TESTING_RU.md` — как проверять; `README.md` — что умеет мод.

## Идентификаторы и статусы

- Задачи: `T-NNN`, баги: `B-NNN`, идеи: `R-NNN`, решения: `D-NNN`. Номера не
  переиспользуются; удалённое помечается статусом, а не стирается.
- Статусы задач: `todo` → `в работе` → `ревью` → `готово`; также `блок` (с причиной)
  и `отменено`.
- Статусы багов: `открыт`, `в работе`, `исправлен` (с коммитом и проверкой),
  `не воспроизводится`, `не баг`.
- Серьёзность багов: `S1` — падение, порча мира/сохранений; `S2` — ломает
  механику; `S3` — неверное, но обходимое поведение; `S4` — косметика.
- Ссылки на ветки, коммиты (короткий SHA), отчёты `docs/validation/...` и
  перекрёстные ID (`B-003` в задаче, `T-010` в баге) обязательны там, где они есть.
