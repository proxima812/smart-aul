# Структура проекта и очистка

## Что удалено

- `recovery/alternative-cfr`, `normalized-cfr`, `normalized-source`: старые дубли декомпилированных исходников.
- `recovery/normalized.jar`, промежуточные дампы байткода, логи неудачных сборок,
  временные результаты восстановления и старые инструменты повторной декомпиляции.
- `dist`: устаревший JAR Independent Villagers, дубликат JAR Smart Aul и их старые контрольные суммы.
- `.github/modernize`: вспомогательные скрипты записи вызовов инструментов; CI-процесса там не было.
- Старые корневые логи, кроме занятого процессом `logs/latest.log`.
- Старые классы в выходном каталоге удалены через `gradlew clean`.

Массовое удаление с `-Force` было отклонено автоматической проверкой.
Очистка выполнена обычными командами PowerShell без `-Force`, после проверки
абсолютных путей внутри проекта. Занятый файл принудительно не освобождался.

## Что сохранено и перенесено

| Каталог | Назначение |
|---|---|
| `src/main/java/net/smartaul` | Код мода, точка входа `SmartAulMod` |
| `config` внутри Java-пакета | Настройки, перенос старого конфига, правила развития |
| `command` внутри Java-пакета | Пользовательские и разработческие команды |
| `village` внутри Java-пакета | Поселения, строительство, экономика, задачи жителей |
| `client/render` внутри Java-пакета | Клиентские модели, слои и состояние рендера |
| `mixin` и `api` внутри Java-пакета | Интеграции с Minecraft и API деревни |
| `gradle/mappings` | Локальные intermediary mappings, обязательные для сборки |
| `docs/project` | План, журнал готовых шагов, баги, планы на будущее, решения |
| `docs/history` | История восстановления и таблица переименований |
| `docs/validation` | Сохранённые отчёты и выбранные доказательства проверок |
| `tools/dev` | Утилиты RCON и чтения тестовых NBT |
| `run/servers/development` | Перенесённый тестовый сервер вместе с миром и настройками |
| `run/servers/packaged` | Перенесённая проверка готового JAR вместе с миром и настройками |
| `run/saves` | Существующие клиентские миры, если они есть |

`README.md` — единственное актуальное описание; `README_RU.md` ссылается на него.
`TESTING_RU.md` содержит сценарии проверки. Старые отчёты в `docs/history`
описывают прежнюю структуру; восстановление декомпиляцией больше не является
частью обычной сборки проекта.

`.gradle`, `build` и `run` — рабочие каталоги Gradle и Minecraft. Они игнорируются
Git. Их появление после сборки/запуска нормально; миры в `run` нельзя считать
мусором. Актуальный устанавливаемый мод: `build/libs/smart-aul-1.1.0-dev.jar`.

## Нормализация имён

Классы используют читаемые имена, пакет `r` заменён на `village`, корень пакетов
— `net.smartaul`. Обновлены импорты, строковые проверки принадлежности задач,
метаданные Fabric, конфигурация Mixin и команда запуска регрессий.
51 обработчик Mixin и 9 accessor/invoker-методов получили читаемые имена.
Minecraft `class_*`, `method_*`, `field_*` — имена используемых mappings;
их ручная замена нарушила бы интеграцию. Часть внутренних полей и методов
восстановленного кода ещё имеет обфусцированные имена.

Ресурсные ID и NBT-ключи `smart_colonies` оставлены для совместимости миров.
Генерируемые игровые ресурсы не изменялись. Ориентир для регистрации миксинов:
[Fabric Wiki](https://wiki.fabricmc.net/tutorial:mixin_introduction).

## Проверка результата

- Чистая сборка `gradlew.bat clean build` и 327 регрессионных проверок прошли.
- Перенесённый сервер загрузил существующий мир и два поселения; команды
  диагностики выполнились, сохранение и остановка прошли штатно.
- Проверены точка входа и наличие всех 32 миксинов в готовом JAR.
- Утилиты в `tools/dev` прошли `py_compile`.
- Старых Java-пакетов и обфусцированных имён классов в исходниках не осталось.
- `git diff --check` прошёл; клиентский рендер после переноса пакетов
  отдельно в игре не проверялся.
