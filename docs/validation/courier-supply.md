# T-011: склад, курьер и заявки

Ветка `t3/c06fdda4`, 2026-11-08. Реализация собственная, без материалов MineColonies.

Исходный поток подробно зафиксирован в D-005 (`docs/project/DECISIONS.md`):
склады колонии → выбор склада работником → подход → забор в инвентарь →
расход при постройке; добытчики используют существующий путь сдачи добычи.
`RepairTask` ставит начальный склад, ремонт выполняет `ColonyTravelTask`.
`MaterialRequirement` используется для припасов экспедиций.

Теперь `HouseBuilderTask` и `ColonyTravelTask` при наличии живого загруженного
курьера ожидают заявку; остальные прежние ветки снабжения сохранены.
`MaterialRequests` хранит приоритет, срок, состояния, lease и единственный
счётчик груза; `CourierTask` раз в 20 тиков вызывает серверный `CourierSupply`.
Взятый груз не находится одновременно в сущности. Навигация использует
существующий ограниченный маршрут, только загруженные цели до 96 блоков;
получатель не должен уйти дальше 16 блоков от позиции заявки.

Один курьер выделяется из бюджета работников при складе, населении от
`courier_min_population=10` и восьми доступных работниках. `COURIER` добавлен
после всех прежних значений; строковая сериализация ролей сохранена.
Очередь видна через общий вывод ратуши и `/smart_aul plan`.

  с локальными mappings; исправлено по фактическим сигнатурам, mappings не менялись.
- `build runGameTest` после исправления: PASS; регрессии курьера PASS,
  существующие регрессии PASS; GameTest 5/5, включая доставку после NBT round-trip.
- Финальный повтор после дополнения проверок и локализации: BUILD SUCCESSFUL
  (46 с), Courier PASS, Development 96 994 PASS, остальные suites PASS, GameTest 5/5 PASS.
  Лог `build/t011-final-validation.log`, XML `build/reports/gametest/results.xml`.
- `git diff --check`: PASS. JAR содержит классы курьера без тестовых классов.

Не проверено вручную: движение курьера в поселении, весь цикл назначения и
активностей AI, настоящая смерть/выгрузка, остановка и повторный запуск процесса.
GameTest отключает AI и проверяет производственные операции рядом со складом.
NBT round-trip — реальный сериализатор колонии, но не перезапуск всего мира.
Для нестандартных компонентов транспорт намеренно не применяется; аварийный
краш между записями разных файлов Minecraft не покрывается гарантией атомарности.
