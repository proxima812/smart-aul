## Ограничения

Визуальное отображение в игровом мире **не проверено**, скриншота голограммы нет.
Запуск клиента подтверждает bootstrap, но не сетевую доставку и выполнение
world-render callback. Отдельный dedicated server с vanilla-клиентом не проверен.
Не выполнены игровые сценарии смены измерения, защиты земли и выгрузки чанков.
Обновление имеет задержку до 3 секунд; большая схема может быть обрезана лимитом.
Динамические модели block entities не воспроизводятся, используются обычные baked
quads. Оценка запасов дана отдельно по каждой стройке, без общего резервирования
и без предметов у работников. Неизвестные выгруженные блоки отмечены в прогрессе.
