# Регрессии логики без серверного мира

Проверено 2026-11-08, новый набор `LogicRegression`: **935 checks**.
Он вызывается одной строкой рядом с `NavigationSafetyRegression.run()`.

Покрытие наблюдаемого поведения:

- `LandClaim`: сетка внутри/снаружи и на границе квадратного участка, независимость
  от высоты, касание/разрыв/вложение bounding box, ограничение радиуса, NBT,
  старое поле радиуса и неверный UUID.
- `ColonyWorldData` / `TimedReservation`: владение блоками, чужие блоки на границе,
  начало/конец срока 1200 тиков, другой владелец, обратное время, очистка,
  отрицательные координаты чанков, NBT и восстановление пространственного индекса.
  Резервирования временные: после загрузки их нет.
- `LandClaimManager` (частично): идентификация документов и реальные NBT-адаптеры
  предупреждений, пропуск неверного UUID, ограничение счётчика и длинные тики.
- `InventoryMaterials` / `ItemStackKey`: объединение стопок и разницы запасов.
- `OfflineDevelopment` (частично): преобразование молока в пустые вёдра,
  резерв, ёмкость инвентаря, сохранение количества и повторный вызов.
- `VillageEconomy`: точные расчёты цен/партии и ограничения значений.
- `ColonyCrafting` / `CraftingRecipe` (частично): реальные предикаты рецептов,
  пустые/посторонние предметы, количество и пользовательские компоненты.
- `PropertyDeeds` (частично): уровни, использованный/привязанный документ,
  обычная бумага, метаданные на неверном предмете.
- `WallBlockPlan` / `VillageDefenseState`: NBT через `Colony`, порядок очереди,
  состояние блока, флаг удаления, длинный тик и неверные счётчики.

Багов production-кода этим прогоном не обнаружено; `src/main` не менялся.

Не покрыто: `SearchBudget` (потребление вызывается через серверный тик в
`ColonyManager`); `ProtectedLand`, `BuildingSiteValidator`, `ColonyTrading` /
`TradeContext`, выполнение крафта и `EquipmentRecipe` / `MaterialRequirement`
(потребители требуют серверный мир, жителей, чанки либо склады). `ResourceCounts`
сам по себе — пара координат; отдельные accessor-тесты не добавлялись.
Полная офлайн-симуляция за 1 и 30 дней, ограничение роста и отсутствие бесплатного
снабжения **не проверены**: путь `ConstructionManager` требует живого серверного
мира. Проверка преобразования вёдер этого не подтверждает. Выдача и применение
документов, защита земли и выполнение стен в игре также не проверялись.

Проверки: `./gradlew.bat build` — PASS, `Logic regressions: PASS (935 checks)`,
существующий `Development regression: PASS (96994 checks)`; `git diff --check` — PASS.
