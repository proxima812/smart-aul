## Регрессия `longRouteTrap`

- Ловушка 40×80 при цели в 170 блоках: повтор одноразовых поисков по 100 узлов
  застревает в кармане (контроль стенда); сессия со срезами по 100 узлов проходит,
  3853 узла (оптимальный A* — 11 561), стоимость в пределах веса 125 %,
  результат совпадает с поиском без срезов.
- Цель в 300 блоках, за окном ±192: карман 100×220. Этапы с узлом, ближайшим к цели
  по прямой, застревают у стены (контроль); этапы по узлу фронтира с минимальной f
  доходят (в замере — 6 этапов).
- Для 30 Dijkstra-карт результат при любой нарезке равен одноразовому `find`.
