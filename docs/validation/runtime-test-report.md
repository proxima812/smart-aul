  guard, lumberjack, miner, farmer, fisherman, rancher, elder сохранены.

- Клиент оставлен на паузе возле центра деревни для ручного теста.

## Найденное и исправленное

Vineflower подставил имена обфусцированных полей вместо фактических имён Enum.
В оригинальном байткоде поле `x35csp4lojh59r` создаёт значение с name=`BUILDER`.
В первом восстановленном исходнике name стал `x35csp4lojh59r`, из-за чего ломались
ключи переводов и имена для сериализации. Восстановлены исходные значения enum,
старые бинарные имена полей сохранены как aliases. Исправление включено в
`source-repairs.json`; регрессионная проверка — `VerifyEnumNames.java`.

модами, мультиплеер, экспедиции и полный цикл строительства не проверялись.
