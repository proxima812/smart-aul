# Independent Villagers — восстановленный проект

Оригинал: 1.0.20-beta.40, Minecraft 1.21.11, Fabric Loader 0.18.4+, Java 21.

## Результат восстановления

Проект собирается командой `./gradlew.bat build`. Готовый мод:

`build/libs/independent-villagers-restored-1.0.20-beta.40-restored.jar`

Архив с суффиксом `-sources.jar` содержит исходники; он не предназначен для папки `mods`.

Восстановлены 985 зашифрованных строк и 1796 скрытых статических вызовов.
Упрощён 81 переход через константный switch. После повторной декомпиляции
исправлены типы коллекций, область видимости переменных, доступ к бывшим
вложенным классам и виртуальные точки входа Minecraft.

Проверены все 152 класса и 882 метода оригинала (исключая приватные и
вспомогательные synthetic-методы; bridge-методы включены). Отсутствующих методов
нет. Все 1092 исходных ресурса сохранены побайтно. В готовом JAR отдельно
проверены ресурсы и ссылки на классы из метаданных; служебный MANIFEST.MF
формируется Gradle.

Проверен запуск клиента через Fabric Loom и отдельного тестового мира: колония
регистрируется, жители работают, шахтёр доставляет камень на склад, рыбак ловит
рыбу, строитель выполняет задание. Исправлены 42 исходных имени enum в 7 классах:
они нужны для переводов, сериализации ролей и Enum.valueOf. Проверка имён,
порядка значений и сохранения ролей проходит. Полная игровая эквивалентность,
завершение строительства и работа на выделенном сервере пока не проверены.
Подробности: `recovery/runtime-test-report.md`.

## Сборка

Нужны JDK 21 для компиляции и совместимый с Gradle 9.4.1 JDK для запуска
сборщика (здесь использован JDK 25). Gradle автоматически ищет установленный JDK 21.

```powershell
.\gradlew.bat build
```

Зависимости: Fabric Loom 1.15.5, Fabric API 0.141.4+1.21.11.
Настройка окружения опирается на официальную документацию:
https://wiki.fabricmc.net/tutorial:setup

Имена Minecraft `class_…`, `method_…`, `field_…` пока сохранены в intermediary.
Файл `recovery/intermediary-dev-mappings.jar` задаёт идентичное пространство
имён разработки для Loom. Это сохраняет селекторы mixin; миграция на Yarn
человекочитаемые имена ещё не выполнена. Имена классов самого мода обфусцированы.
Ресурсы и оригинальная версия в `fabric.mod.json` не изменены.

## Файлы и проверки

- `src/main/java/` — восстановленные исходники, включая mixin.
- `src/main/resources/` — оригинальные ресурсы.
- `recovery/build-final.log` — итоговая сборка.
- `recovery/restoration-verification.json` — контрольные суммы и проверка ресурсов.
- `recovery/abi-verification.txt` — проверка классов и методов.
- `recovery/source-repairs.json` — точные исправления 76 Java-файлов после декомпиляции.
- `recovery/build-runtime-fix.log` — сборка после исправления enum.
- `recovery/enum-verification.txt` — регрессионная проверка enum.
- `recovery/bytecode-javap.txt`, `alternative-cfr/`, `problem-locations.txt` — исходные материалы восстановления; список проблем описывает прежнее состояние.

## Повторение восстановления

`recovery/tools/recover.ps1` принимает пути к исходному JAR, ASM, ASM Tree и
Vineflower. Использованы ASM 9.9.1 и Vineflower 1.11.2. Программа не загружает
и не исполняет классы мода: криптографические константы разбираются как данные.
Контрольная сумма оригинала проверяется до обработки. Исправления исходников
применяются только к файлам с ожидаемыми SHA-256.

```powershell
.\recovery\tools\recover.ps1 -OriginalJar <original.jar> -AsmJar <asm.jar> -AsmTreeJar <asm-tree.jar> -VineflowerJar <vineflower.jar>
.\gradlew.bat build
```

Для повторения с нуля `prepare_sources.py` ожидает intermediary mappings Minecraft
1.21.11 в стандартном кэше Loom: `.gradle/caches/fabric-loom/1.21.11/intermediary-v2.tiny`
в домашней папке пользователя. Для обычной сборки этот кэш заранее не нужен:
готовый файл mappings включён в проект.
